ببین رکادی‌ها الان کجان؟

برای مشاهده سوابق، پروژه‌ها و مسیر شغلی فارغ‌التحصیلان، ابتدا شعبه مورد نظر خود را انتخاب فرمایید:

یکی از دو کارت بالا را انتخاب کنید

برای مشاهده اختصاصی مشخصات و رزومه‌های هر بخش، لطفاً روی کارت «هنرستان دخترانه» یا «هنرستان پسرانه» کلیک کنید تا گرید کامل بارگذاری شود.

می‌خوای جزو نسل بعدی رکادی‌ها باشی؟

پیش‌ثبت‌نام و تعیین‌سطح هنرستان دخترانه و پسرانه استارتاپی رکاد برای سال تحصیلی جدید آغاز شده. کافیه فرم پیش‌ثبت‌نام رو تکمیل کنی تا باهات تماس بگیریم.
